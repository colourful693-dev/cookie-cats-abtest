# Cookie Cats 手游A/B测试
## 项目背景
Cookie Cats是移动端休闲游戏，游戏设置关卡弹窗。
- 对照组 gate_30：玩家到达30关触发弹窗
- 实验组 gate_40：弹窗延后至40关触发

**实验假设**
$H_0$：延后弹窗不会提升玩家平均游玩关卡数，$\mu_{gate40} \le \mu_{gate30}$
$H_1$：延后弹窗会提升玩家平均游玩关卡数，$\mu_{gate40} > \mu_{gate30}$
检验类型：单侧独立样本t检验

### 指标体系
- 核心指标：`sum_gamerounds`：用户安装游戏后累计游玩关卡数（连续型指标）
- 辅助风险指标：`retention_7`：7日留存率，安装7天后用户是否仍登录游戏，二分类指标，用于评估改动对长期用户留存的负面影响

## 代码执行流程（与代码一一对应，新增辅助指标环节）
1. 导入依赖库，读取本地csv数据集，查看数据集维度、分组数量，检查缺失值、重复值
2. 对`sum_gamerounds`进行描述统计，计算均值、标准差、偏度、峰度，同时计算95%置信区间，绘制原始数据箱线图
3. 数据清洗：识别并剔除sum_gamerounds全局最大值异常样本，重置索引
4. 分组聚合计算两组关卡均值；对关卡数做`log1p`对数变换，绘制分组箱线图，缓解右偏分布便于可视化对比
5. 划分对照组`gate_30`与实验组`gate_40`；设定显著性水平α=0.05，β=0.2，预期效应量=5，计算实验所需最小样本量
6. 设置随机种子42，从两组中抽取对应数量的随机样本，对抽样样本做对数变换并绘制箱线图
7. 统计检验：Leven方差齐性检验，根据方差齐性结果选择独立样本t检验参数，采用单侧检验；输出t统计量、p值，判断是否拒绝原假设
8. 计算两组均值、均值差值，手动计算均值差异的95%置信区间
9. **辅助指标验证：7日留存率检验**：分组统计gate_30与gate_40的7日留存人数与留存率；构建列联表，使用卡方检验判断两组7日留存率是否存在统计学差异，绘制留存对比柱状图。

## 实验最终结论
延后弹窗仅带来平均0.97关的关卡提升，远低于预设5关目标，t检验不显著，对游玩关卡无实质影响；同时7日留存卡方检验显著下降（gate_30：19.02%，gate_40：18.20%，p=0.0016）。综合评估，该改动无正向收益且损害长期留存，**不建议上线**。
